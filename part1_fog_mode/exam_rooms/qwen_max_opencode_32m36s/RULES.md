### 2. 进程级隔离与计时红线
* **独立干净沙盒**：正式评测时，每一个 `(勇者, 目标地图)` 对局都在全新的独立子进程中运行，初始传入 `memory = {}`，固定随机种子 `random.seed(20261115)`，无法通过模块全局变量跨局传递数据。**第一场正赛全部采用 `"BLIND"` 迷雾盲视模式评测**（全图明牌破阵 `FULL` 模式将在独立的第二场赛程中另行提交专用代码）。

  * 模块首次 `import submission` 限时 **`1.5 秒`**；

  * 若 `decide_action` 超时（$>0.5\text{s}$）、抛出未捕获异常、或返回值不属于 14 种合法动作字符串，视为一次**接口错误**：本回合动作强制替换为 `"WAIT"`，且连续错误计数 `error_streak += 1`；若 `error_streak == 3`（连续 3 回合接口错误），勇者当即暴毙判负。

## 二、 赛场空间、四层状态模型与 3000G 金库经济

### 1. 画布尺寸与地标硬性约束（违反任意一条则魔王图 0 分废标）
* **网格尺寸**：宽 `40` 列（$x \in [0, 39]$），高 `26` 行（$y \in [0, 25]$），共 `1,040` 格。二维数组按 `grid[y][x]` 索引（`grid` 必须为包含 26 个长度为 40 的字符串列表）。
* **免费外框边界**：最外圈 128 格（即 $x \in \{0, 39\}$ 或 $y \in \{0, 25\}$）必须全部填写 `"T_W"`（钛金承重墙）。**外框这 128 格造价为 `0G`，且不计入 `"T_W"` 的 120 格单图限购配额！**
* **出生净空区（Spawn Clearance Zone）**：
  * 勇者出生点固定在 `S = (2, 13)`（即 $x=2, y=13$）。
  * 以 `(2, 13)` 为中心的 $3\times 3$ 区域（$x \in [1, 3], y \in [12, 14]$，共 9 格）为出生净空区，魔王提交的 `grid` 中这 9 格**必须全部填写 `"EMPTY"`**（禁止放置任何墙体、机关、箱子、地标或专属骸骨线索）。外部激光射线允许穿过该区域（第 3 回合才会首次发射）。
* **三座必放核心地标（造价均为 `0G`，全图各恰有 1 个，坐标互异）**：
  1. **`"K1"`（上半区钥匙）**：必须满足 $x \in [12, 34]$ 且 $y \in [2, 10]$；
  2. **`"K2"`（下半区钥匙）**：必须满足 $x \in [12, 34]$ 且 $y \in [15, 23]$；

* **通关条件**：勇者必须先拾取 `"K1"` 和 `"K2"`（先后顺序不限），随后在存活状态（$\text{HP} > 0$）下踏上 `"V"` 金库格，当即判定通关成功！

### 3. 裁判内核四层真值解码规则（Four-Layer Truth Model）
魔王提交单层 `grid[26][40]` 后，裁判立即按以下规则解码为 4 个图层运行：
1. **`terrain[y][x]`（地形层）**：若 `grid[y][x]` 为 `"BOX"` 或 `"TNT"`，则 `terrain[y][x] = "EMPTY"`；否则 `terrain[y][x] = grid[y][x]`。
2. **`occupant[y][x]`（实体占用层）**：若 `grid[y][x]` 为 `"BOX"` 或 `"TNT"`，则 `occupant[y][x] = grid[y][x]`；否则为 `None`。当箱子移动时只更新 `occupant` 层，不破坏底下的 `terrain`！
3. **`bombs`（定时炸弹列表）**：初始为空列表 `[]`。
4. **`clues[y][x]`（宝箱怪专属骸骨线索层）**：
   * 初始全为 `False`。裁判按行优先（$y$ 从 $0\to 25$，$x$ 从 $0\to 39$）遍历每个 `"MIMIC"` `(mx, my)`，按固定顺序 **`U(0,-1), D(0,1), L(-1,0), R(1,0)`** 检查正交四邻 `(nx, ny)`，选择**第一个**同时满足以下条件的格子作为该 `"MIMIC"` 的绑定专属线索格：
     1. 初始 `terrain[ny][nx] == "EMPTY"` 且 `occupant[ny][nx] is None`；
     2. 不在出生净空区（$x \in [1,3], y \in [12,14]$）内；
     3. 该格 `(nx, ny)` 的正交四邻中**不存在任何其他宝箱**（即除了当前 `(mx, my)` 外，不与任何其他 `"HEAL"` 或 `"MIMIC"` 正交相邻），且 `clues[ny][nx]` 尚未被占用。
   * **违章红线**：若任何一个 `"MIMIC"` 找不到满足上述条件的专属线索格，该魔王地图直接判**布局违章（0 分废标）**！
   * **动态清除**：当某个 `"MIMIC"` 被勇者踩爆、被箱子碾碎、被飞石打爆或被炸弹/TNT 炸毁时，其绑定的专属 `clues[ny][nx]` 立即同步重置为 `False`。

## 三、 确定性物理引擎：4 阶段与 8 步原子位移规范

### 1. 基础概念与阻挡集合
* 方向向量：`U = (0, -1)`, `D = (0, 1)`, `L = (-1, 0)`, `R = (1, 0)`。
* **高墙阻挡物（`HIGH_WALL`）**：`terrain[y][x]` 属于 `{"W", "T_W", "LASER_U", "LASER_D", "LASER_L", "LASER_R"}`，或当前处于**关闭状态**的门（当 `gates_flipped == False` 时 `"R_GATE"` 为高墙、`"B_GATE"` 为平地；当 `gates_flipped == True` 时 `"B_GATE"` 为高墙、`"R_GATE"` 为平地）。
* **门格特权**：开关翻转后新门态立即生效。若某扇门变为关闭时，勇者或 `"BOX"` 正停留在门格上，该实体可停留或正常移出该门格（不受挤压伤害），但其他实体不得进入。

### 2. 单次成功位移的 8 步原子结算序（Atomic Displacement Pipeline）
每当实体（`hero` 或某个 `"BOX"`）从原坐标 `p0 = (x0, y0)` 成功进入目标格 `p1 = (x1, y1)`（含普通迈步、冰面滑入、斜坡折转滑入、跳跃落点、弹簧落点、传送到达配对端），严格按以下 8 步顺序执行：

1. **位移计数递增**：该实体在当前动作链中的成功位移计数 `steps_taken += 1`。
2. **原格离开钩子（Leave Hook）**：检查原格 `terrain[y0][x0]`：若为 `"CRACK"`（无论走离、跳离、弹簧起飞还是传送离开），立即将 `terrain[y0][x0]` 永久修改为 `"PIT"`！
3. **更新坐标与暴露轨迹**：
   * 若实体为 `"BOX"`：将 `occupant[y0][x0] = None`，`occupant[y1][x1] = "BOX"`；
   * 若实体为 `hero`：更新 `(hx, hy) = (x1, y1)`，并将 `(x1, y1)` 加入本回合激光暴露轨迹集合 `exposed_cells`。
4. **落点即时效果（Arrive Hook）**：检查落点 `terrain[y1][x1]`：
   * **若实体为 `"BOX"`**：
     * `"PIT"`：箱子与深渊同归于尽——`occupant[y1][x1] = None`，`terrain[y1][x1] = "EMPTY"`，并立即终止该箱子的动量链；
     * `"MIMIC"`：箱子碾碎宝箱怪——`terrain[y1][x1] = "EMPTY"`（同步清除其专属线索）；
     * `"SWITCH"`：`gates_flipped = not gates_flipped`；
   * **若实体为 `hero`**：
     * `"PIT"`：受到 `100` 点机关伤害（`hp -= 100`）；
     * `"MIMIC"`：受到 `45` 点机关伤害（`hp -= 45`），`terrain[y1][x1] = "EMPTY"`（同步清除其专属线索），并标记 `stop_momentum = True`；
     * `"HEAL"`：`hp = min(100, hp + 30)`，`terrain[y1][x1] = "EMPTY"`；
     * `"SWITCH"`：`gates_flipped = not gates_flipped`；
5. **死亡即时截断**：若 `hero.hp <= 0`，立即终止本回合与整局游戏，判定勇者阵亡！
6. **拾取钥匙与通关即时截断**：
   * 若实体为 `hero` 且 `terrain[y1][x1] == "K1"`：`has_k1 = True`，`terrain[y1][x1] = "EMPTY"`；
   * 若实体为 `hero` 且 `terrain[y1][x1] == "K2"`：`has_k2 = True`，`terrain[y1][x1] = "EMPTY"`；
   * 若实体为 `hero` 且 `terrain[y1][x1] == "V"` 且 `has_k1 and has_k2` 且 `hero.hp > 0`：**立即终止本回合与整局游戏，判定勇者存活通关（不再执行后续阶段 C 与阶段 D）**！
7. **位移上限与动量停止检查**：若 `steps_taken >= 32` 或 `stop_momentum == True`，立即终止该实体本次动作链的后续动量延伸，停在 `p1`。
8. **动量延续判定（Momentum Continuation）**：根据此刻 `terrain[y1][x1]` 决定是否发起下一次位移（若刚刚是通过传送到达配对端且 `suppress_portal_once == True`，则跳过下方 `"PORTAL_*"` 分支，改按下方门后迈步规则处理）：
   * **若为 `"ICE"`**：保持当前方向 `dir = (dx, dy)`，检查下一相邻格 `p_next = (x1+dx, y1+dy)` 是否可入（非 `HIGH_WALL`，且 `occupant` 非 `"BOX"`/`"TNT"`；若当前实体为 `"BOX"`，还要求 `p_next` 非勇者当前坐标且 `terrain` 非 `"K1"/"K2"/"V"`）。若可入，对 `p1 -> p_next` 递归执行本 8 步原子序；若受阻，则停在 `p1`，动量终止。
   * **若为 `"MIRROR_NE/SE/SW/NW"`**：先按折跃表将 `dir` 折转 $90^\circ$，再按与 `"ICE"` 完全相同的可入性规则检查新方向下一相邻格 `p_next`：可入则滑入 `p_next` 执行 8 步原子序，受阻则停在当前斜坡格上。
   * **若为 `"SPRING_U/D/L/R"`**：将 `dir` 改为弹簧朝向，向该方向逐格探测 $k = 1, 2, 3$（记 `pk = (x1 + k*dx, y1 + k*dy)`）：
     * 阻挡条件：`pk` 为 `HIGH_WALL`、`occupant[pk]` 为 `"BOX"` 或 `"TNT"`，或者当实体为 `"BOX"` 时 `pk` 为勇者坐标或 `"K1"/"K2"/"V"`。
     * 若在第 $k \in \{1, 2, 3\}$ 格首次遇到阻挡：
       * **特殊交互**：若当前弹射实体为 `"BOX"` 且阻挡物为 `"TNT"`，将该 `"TNT"` 标记为待爆（`tnt_armed.add(pk)`）！
       * 若 $k == 1$（紧贴阻挡物）：实体留在弹簧原格 `p1`，动量直接终止（不计新位移，绝不重复触发该弹簧）；
       * 若 $k \in \{2, 3\}$：实体腾空飞越中间格，提前落在 `p_{k-1}`（作为一次从 `p1 -> p_{k-1}` 的成功位移执行 8 步原子序）！
     * 若 $k = 1, 2, 3$ 均无阻挡：实体腾空飞越 `p_1, p_2`（中间两格不触发任何效果、不加入 `exposed_cells`），直接落在 `p_3`（作为一次从 `p1 -> p_3` 的成功位移执行 8 步原子序）！
   * **若为 `"PORTAL_1A/1B/2A/2B"`**（且非刚从配对端传过来）：
     * 查找其配对门坐标 `p_pair`。检查 `p_pair` 是否可入（`occupant[p_pair]` 为 `None`，且若实体为 `"BOX"` 则 `p_pair != (hx, hy)`）。若不可入，留在入口门 `p1` 并终止动量；
     * 若 `p_pair` 可入：实体传送至 `p_pair`，递增该实体本回合传送计数 `portal_count += 1`，作为一次从 `p1 -> p_pair` 的成功位移执行第 1~7 步；
     * 在第 8 步到达 `p_pair` 后：**若 `portal_count >= 2`，实体在第二个配对端 `p_pair` 直接停稳，动量终止！** 若 `portal_count == 1`，实体保持进入方向 `dir` 尝试向 `p_pair` 前方相邻格迈出 1 格普通位移（可入则进入下一格并继续根据下一格地形结算，受阻则停在 `p_pair` 上）。
   * **其余地形（`"EMPTY"`, `"CRACK"`, `"SWITCH"`, 开启的门, `"K1"`, `"K2"`, `"V"` 等）**：普通摩擦地面，实体停稳，动量终止。

### 3. 单回合 4 阶段主循环（Turn Master Pipeline）
每回合（`turn = 1 .. 240`）开始时，初始化 `exposed_cells = {(hx, hy)}`。

#### ▶ 阶段 A & B：起手动作与动量链
1. **`"WAIT"`**：不移动（不触发脚下离开或进入效果）。
2. **`"BOMB"`**：若 `hero.bombs > 0` 且当前坐标 `(hx, hy)` 上没有未爆炸弹，则 `hero.bombs -= 1`，在 `bombs` 列表末尾追加 `{"id": next_id, "x": hx, "y": hy, "timer": 3}`。否则等效于 `"WAIT"`。
3. **`"MOVE_U/D/L/R"`**：设目标格 `p1 = (hx+dx, hy+dy)`：
   * 若 `p1` 为 `HIGH_WALL` 或 `occupant[p1] == "TNT"`：撞墙受阻，留在原地；
   * 若 `occupant[p1] == "BOX"`：检查箱后一格 `p2 = (hx+2*dx, hy+2*dy)` 是否对箱子可入（非 `HIGH_WALL`、`occupant[p2]` 为 `None`、且 `terrain[p2]` 非 `"K1"/"K2"/"V"`）：
     * 若 `p2` 不可入：推箱受阻，勇者留在原地；
     * 若 `p2` 可入：**先让该 `"BOX"`（初始 `steps_taken=0, portal_count=0`）从 `p1 -> p2` 启动并完整跑完箱子的动量链**（期间勇者原格 `(hx, hy)` 视为阻挡箱子的障碍物）。箱子动量链彻底结束后，重新检查 `p1` 格此刻是否对勇者可入（例如箱子可能折返停回 `p1`，或箱子踩了开关把 `p1` 处的门关上了）：仅当 `p1` 此刻对勇者可入时，勇者才（以 `steps_taken=0, portal_count=0`）从 `(hx, hy) -> p1` 迈入并跑完勇者的动量链！（注意：若 `p1` 原本是 `"CRACK"`，箱子被推离 `p1` 的瞬间 `p1` 已变为 `"PIT"`，勇者紧接着迈入 `p1` 将直接掉入深渊 `-100 HP` 暴毙！）
   * 若 `p1` 无阻挡且无箱子：勇者直接从 `(hx, hy) -> p1` 迈入并跑完动量链。
4. **`"JUMP_U/D/L/R"`**：
   * 若 `hero.jumps == 0`：按 `"WAIT"` 处理；
   * 否则先扣减 `hero.jumps -= 1`。设第 1 格 `p1 = (hx+dx, hy+dy)`，第 2 格 `p2 = (hx+2*dx, hy+2*dy)`：
     * **起跳阻挡检查**：若 `p1` 为 `HIGH_WALL`，或者 `p2` 为 `HIGH_WALL`、`"BOX"` 或 `"TNT"`，则跳跃受阻失败，勇者留在原地（不触发 `p0` 离格，但跳跃次数已扣除）；
     * **成功腾空跨越**：勇者跃过 `p1`（`p1` 上的任何陷阱/钥匙/深渊均不触发，也不加入 `exposed_cells`），直接作为一次从 `p0 -> p2` 的成功位移（`steps_taken=0, portal_count=0, dir=(dx,dy)`）执行 8 步原子序（注意：`p0` 若为 `"CRACK"` 会在第 2 步正常坍塌为 `"PIT"`，`p2` 落点正常结算并延续动量）！
5. **`"THROW_U/D/L/R"`**：
   * 若 `hero.throws == 0`：按 `"WAIT"` 处理；
   * 否则扣减 `hero.throws -= 1`。勇者留在原地，飞石从 `(sx, sy) = (hx, hy)` 沿 `dir = (dx, dy)` 射出，初始空中剩余射程 `range_left = 6`，传送计数 `stone_portals = 0`：
   * **空中飞行循环（当 `range_left > 0`）**：
     * 飞石进入下一相邻格 `pn = (sx+dx, sy+dy)`，消耗 `range_left -= 1`，更新 `(sx, sy) = pn`：
     * 若 `pn` 为 `HIGH_WALL` 或 `occupant[pn] == "BOX"`：飞石撞击碎裂，飞行结束；
     * 若 `occupant[pn] == "TNT"`：将该桶标记待爆 `tnt_armed.add(pn)`，飞石碎裂结束；
     * 若 `terrain[pn] == "SWITCH"`：`gates_flipped = not gates_flipped`，飞石碎裂结束；
     * 若 `terrain[pn] == "MIMIC"`：将 `terrain[pn]` 打爆清除为 `"EMPTY"`（同步清除其专属线索），飞石碎裂结束；
     * 若 `terrain[pn]` 为 `"MIRROR_*"`：按斜坡四向表折转 `dir`（每进入一格只折转一次），若 `range_left > 0` 继续向新方向飞行；
     * 若 `terrain[pn]` 为 `"PORTAL_*"`（且 `stone_portals < 2`）：检查配对端 `p_pair` 是否无 `"BOX"`/`"TNT"` 占用；若可入，飞石瞬间移至 `p_pair`（传送本身不额外消耗 `range_left`），`stone_portals += 1`；若 `stone_portals == 2` 则在 `p_pair` 直接停止，否则继续沿 `dir` 消耗剩余射程飞行；
     * 其余地形（`"EMPTY"`, `"PIT"`, `"CRACK"`, `"ICE"`, `"SPRING_*"`, `"HEAL"`, `"K1"`, `"K2"`, `"V"`）在空中完全透明飞越。
   * **第 6 格落地滑行延伸**：当 `range_left == 0` 且飞石尚未碎裂时，仅当此刻所在的第 6 格 `terrain[sx][sy]` 为 `"ICE"` 或 `"MIRROR_*"` 时，飞石转入地面滑行模式（最多滑行 32 步）：每步沿 `dir` 滑入下一格，途中若遇 `HIGH_WALL`/`"BOX"` 碎裂，遇 `"TNT"`/`"SWITCH"`/`"MIMIC"` 触发对应效果后碎裂，遇 `"MIRROR_*"` 折转继续滑，遇 `"ICE"` 继续滑，遇 `"PORTAL_*"` 按剩余传送次数传送，滑入任何其他地形（如 `"EMPTY"`, `"PIT"`, `"CRACK"`, `"SPRING_*"`）立即停下消失。

#### ▶ 阶段 C：定时炸弹倒计时与链式爆炸闭包
1. 全场现有 `bombs` 中的每颗炸弹 `timer -= 1`；
2. 收集初始爆源集合：所有 `timer == 0` 的 `BOMB` 以及本回合阶段 A/B 中被加入 `tnt_armed` 的 `"TNT"`；
3. 若存在初始爆源，执行 **同批链式爆炸 BFS**：
   * 设爆源队列 `Q`，对每个爆源 `(ex, ey)`，其波及范围为切比雪夫距离 $\le 1$ 的九宫格（$|x - ex| \le 1$ 且 $|y - ey| \le 1$，注：钛金墙 `"T_W"` 自身免疫爆炸，但不遮挡同一九宫格内的对角格）。
   * 若九宫格内存在其他尚未引爆的 `"TNT"` 或尚未引爆的 `BOMB`（无论其 `timer` 是多少），立即将其加入 `Q` 在同一批次内链式引爆（每个爆源唯一计数，单批次只爆一次）。
4. **伤害与地形合并结算（基于批次快照）**：
   * 统计波及勇者当前坐标 `(hx, hy)` 的所有爆源：每颗波及勇者的 `"TNT"` 计机关名义伤害 $+60$，每颗波及勇者的 `BOMB` 计勇者自伤 $+50$。设本批机关名义总伤害为 $a$，自伤总和为 $b$，结算前勇者血量为 $h$：
     * 若 $a + b > 0$，累加本批有效机关伤害 $\Delta D = \min(h, a + b) \times \frac{a}{a + b}$，随后扣减勇者血量 `hp -= (a + b)`。
   * 移除所有已引爆的 `BOMB` 与 `"TNT"`；
   * 对所有爆源九宫格并集内的每个格子 `(cx, cy)`：
     * 若 `occupant[cy][cx] == "BOX"`：箱子被炸毁（`occupant[cy][cx] = None`）；
     * 检查 `terrain[cy][cx]`：
       * `"T_W"`, `"K1"`, `"K2"`, `"V"`, `"PORTAL_1A/1B/2A/2B"`, `"PIT"`：**绝对免疫，保持不变**；
       * `"CRACK"`：**被炸断直接坍塌变为 `"PIT"`**；
       * `"W"`, `"ICE"`, `"MIRROR_*"`, `"SPRING_*"`, `"LASER_*"`, `"SWITCH"`, `"R_GATE"`, `"B_GATE"`, `"HEAL"`, `"MIMIC"`：**被炸毁变为 `"EMPTY"`**（若为 `"MIMIC"` 同步清除其专属线索）。
   * **爆炸后支撑检查**：
     * 若某未被炸毁的 `"BOX"` 脚下地形因爆炸变成了 `"PIT"`，该箱子立即填坑同归于尽（`occupant = None, terrain = "EMPTY"`）；
     * 若爆炸后勇者依然存活（`hp > 0`）但脚下 `terrain[hy][hx] == "PIT"`（例如勇者站在 `"CRACK"` 上被远方爆炸波及炸塌），勇者立即落坑受到 `100` 点机关伤害（记入有效机关伤害并 `hp -= 100`）！
   * 若 `hp <= 0`，立即终止回合判定勇者阵亡！

#### ▶ 阶段 D：周期激光同步快照发射（仅当 `turn % 3 == 0` 时执行）
当 `turn % 3 == 0`（即 `turn` 为 `3, 6, 9, ..., 240`）时：
1. **冻结快照**：以阶段 C 结束后的地图状态为基准，扫描全场所有存活的 `"LASER_U/D/L/R"` 炮座。
2. **同步射线延伸**：每门激光炮同时沿其朝向从相邻第 1 格起延伸最多 **10 格** 直线射线：
   * 逐格检查 $d = 1 .. 10$：
     * 若该格在快照中为 `HIGH_WALL` 或 `occupant == "BOX"`：射线在此格前截断（不包含该阻挡格）；
     * 若该格在快照中 `occupant == "TNT"`：射线在此格截断，并将该 `"TNT"` 标记入 `laser_tnt_armed`！
     * 否则该格属于该门激光炮的本轮激活射线格。
3. **激光命中勇者结算**：
   * 统计所有激活激光炮中，其射线格集合与勇者本回合的暴露轨迹集合 `exposed_cells` 有交集的激光炮数量 $m$；
   * 若 $m > 0$，勇者受到 $50 \times m$ 点纯机关伤害（有效机关伤害累加 $\min(\text{hp}, 50 \times m)$，`hp -= 50 * m`）。若 `hp <= 0`，立即终止回合判定勇者阵亡！
4. **激光引爆 `TNT` 连锁结算**：
   * 若 `laser_tnt_armed` 非空，以 `laser_tnt_armed` 为初始爆源调用阶段 C 的第 3、4 步爆炸闭包结算（**严格规定：此时绝不再次执行阶段 C 第 1 步的 `bombs` 倒计时递减！且本轮已被炸毁的激光炮座不会撤销步骤 3 已造成的激光伤害**）。

* **回合末超时判定**：当 `turn == 240` 的阶段 D 完整执行完毕后，若勇者仍未通关（且未阵亡），则判定本局**超时失败（Timeout）**。

## 四、 双榜计分数学公式与经济博弈指南

设魔王建图花费为 $C_{\text{spent}} \in [0, 3000]$，金库留存比例为 $g = \frac{3000 - C_{\text{spent}}}{3000} \in [0.0, 1.0]$；设整局累计有效机关伤害为 $D = \min(100.0, \sum \Delta D_{\text{trap}}) \in [0.0, 100.0]$，勇者最终已拾取钥匙数为 $k \in \{0, 1, 2\}$，当前阶段推进比为 $r = \max\!\left(0.0, \frac{d_0 - d_{\min}}{\max(1, d_0)}\right) \in [0.0, 1.0)$，连续总进度 $P = k + r \in [0.0, 3.0)$。

### 1. 🗡️ 勇者单局得分 $Score_{\text{Hero}}$（`0 ~ 1000` 连续线性分布）
* **【存活通关】（耗时 $T \in [1, 240]$ 回合）**：
  $$Score_{\text{Hero}} = 600 + 1.5 \times HP_{\text{left}} + 150 \times \frac{240 - T}{239} + 100 \times g$$
* **【闯关失败】（阵亡或满 240 回合超时，三阶段连续线性推进）**：
  $$Score_{\text{Hero}} = 200 \times k + 200 \times r = 200 \times P$$
  *(其中 0 钥阶段占 `0~200` 分、1 钥阶段占 `200~400` 分、2 钥阶段占 `400~600` 分，无缝衔接存活通关的 `600` 分底线。距离采样仅在勇者取得第 $k$ 把钥匙之后的阶段内进行：$d_0$ 为该阶段起点距下一目标的曼哈顿距离，$d_{\min}$ 为该阶段内勇者所有实际到达点距下一目标的最小曼哈顿距离；0 钥阶段下一目标距离定义为 $\min(\text{dist}(K_1), \text{dist}(K_2))$，1 钥阶段为距剩余钥匙距离，2 钥阶段为距 `V` 距离。)*

### 2. 🏰 魔王单局得分 $Score_{\text{Demon}}$（`0 ~ 1000` 连续线性分布）
* **情况 A：【实杀处决勇者】（勇者因 `HP <= 0` 阵亡 —— 全额独吞金库暴利！）**：
  $$Score_{\text{Demon (Kill)}} = 500 + 50 \times (3 - P) + D + 250 \times g$$
* **情况 B：【困死超时勇者】（满 240 回合但勇者 `HP > 0` 存活 —— 基础分与金库暴利折减！）**：
  $$Score_{\text{Demon (Timeout)}} = 320 + 50 \times (3 - P) + D + 125 \times g$$
* **情况 C：【金库失守】（被勇者存活通关 —— 按造成机关伤害与拖延回合连续计分，金库留存归零）**：
  $$Score_{\text{Demon (Breached)}} = 2.0 \times D + 120 \times \frac{T - 1}{239} \quad (\text{区间 } [0, 320]\text{，无缝衔接困死底线})$$

*(注：`author_solution` 必须在最后一个动作恰好首次完成存活通关，严禁在通关后追加冗余动作，否则直接判违章 0 分。)*

### BLIND 圆形视野与墙体遮挡（方案 B 增量约定）

基础候选格保持 `dx²+dy²<=10`，空旷中心恰为37格；存在遮挡或位于边缘时基础可见格少于37格。按 `max(|dx|,|dy|)=0,1,2,3` 由近及远判定。`sx=sign(dx)`、`sy=sign(dy)`，`open(dx,dy)=vis(dx,dy) and not is_high_wall(hx+dx,hy+dy)`，越界视为不透光：

* 近身圈（自身及8邻格）恒可见，贴身墙面本身可见。
* 外圈正交格：仅当 `open(dx-sx,dy-sy)` 为真时可见。
* `(±2,±2)`：须 `open(sx,sy)`，且 `(hx+sx,hy)` 与 `(hx,hy+sy)` 不同时为高墙，禁止斜穿封死的墙角。
* `|dx|>|dy|>0`：`open(dx-sx,dy) or open(dx-sx,dy-sy)`。
* `|dy|>|dx|>0`：`open(dx,dy-sy) or open(dx-sx,dy-sy)`。

目标格可以是可见墙面，但不能继续向后透光。沿用现有 `HIGH_WALL` 定义：`W`、`T_W`、四向 `LASER_*` 炮座及当前关闭的红/蓝门；门随 `gates_flipped` 即时变化。被遮挡的地形为 `UNKNOWN`，骸骨线索不暴露，实体不暴露。相邻8格触发的冰面/折返镜滑道延伸仍使用原逻辑，作为基础视野之外的额外照亮（注：第一场正赛全部以 `BLIND` 迷雾模式运行，`FULL` 全图明牌破阵将独立发卷开赛，不在本场混跑）。
