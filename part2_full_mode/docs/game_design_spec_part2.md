## 二、 冻结规则与计分公式（v2.2 Scheme C 极硬核三连全上）

### 1. 环境与沙盒铁律（冷考官零剧透）
- **视野**：全赛程仅 `mode == "FULL"`，Turn 1 起 `visible_mask` 全盘 `40×26` 恒为 `True`（仅 `HEAL`/`MIMIC` 仍脱敏为 `CHEST`，全图 `clues` 于 Turn 1 全部可见）。
- **时限**：`import <= 1.5s`，`build_dungeon() <= 2.0s`；`decide_action()` **Turn 1 开放 `2.0s` 全局规划预算**，**Turn 2..240 严格 `0.5s`**。
- **超时恢复与三振出局**：单次超时或异常（`error_streak < 3`）时记 `WAIT` 并自动**重建干净工作子进程**（绝不因 Turn 1 卡到 `2.01s` 导致 Turn 2/3 连环死亡）；连续 3 次接口错误判 **`status = "DQ"`**，单列统计，不计入对手魔王的 `lethal_kills` 或 `DEAD` 实杀奖金。
- **考卷隔离**：禁止向任何考场拷贝 `engine_full.py` 或任何对手的地图/`author_solution`；11 名选手收到完全同构字段的本人上半场战报（仅含个人各场死因/DQ/耗时）。

### 2. 三大 `FULL` 专属逻辑新机关（总预算仍 `3,000G`，共 40×26 网格）

| 新组件 | 提交符号 | 单价 | 上限 | 防爆性 | 核心机制（经双审计裁决冻结） |
| :--- | :--- | :---: | :---: | :---: | :--- |
| **金色压板** | `PLATE` | `45G` | `4` | **防爆免疫** | **仅 `BOX` 可触发**（勇者与炸弹不触发！）。`is_plates_active()` 纯动态实时计算：当且仅当地图含至少 1 块压板且**全部 `PLATE` 上均有 `occupant == "BOX"`** 时为 `True`。 |
| **金色压板门** | `P_GATE` | `30G` | `8` | **防爆免疫** | 当 `not plates_active` 时视为高墙（阻挡勇者/箱子/激光/飞石）。校验铁律：若 `P_GATE > 0`，必须满足 **`1 <= PLATE <= BOX`**。箱子推入开门后离板关门不挤压，但闭门内箱子需重开后才能被外部推动。 |
| **重型合金箱** | `BOX` | `30G` | **`6`** *(↑4)* | 可被炸毁 | 上限放宽支持多箱 Sokoban 谜题与 `PIT` 搭桥；Phase C/D 炸毁板上箱子后 `plates_active` 立刻重新派生。 |
| **蓝高频激光** | **`LASER2_U/D/L/R`** | `90G` | **与红炮共享 `12` 门** | **可被炸毁** | 炮座本身为高墙，每 **`turn % 4 == 0`** 同步发射 10 格射线（-50 HP / 引爆 TNT）。与红炮 `turn % 3 == 0` 构成 **`LCM(3, 4) = 12` 拍时空节奏**：单独可徒步穿过；重叠走廊在第 5、7 拍出现 1 拍假空档，第 12/24 拍红蓝齐射 **100 伤秒杀**！`state["laser_warnings"]` 附带 `period`（3 或 4）与 `cannon` 坐标。 |
| **单向通行门** | `ONEWAY_U/D/L/R` | `30G` | `12` | **防爆免疫** | 仅允许实体（勇者与箱子）按箭头方向 `odir` **进入**该格（不限制离开）：覆盖普通 `MOVE`、逆向推箱预检、跟进格、`JUMP` 飞跃格与落点、`ICE` 滑行、`MIRROR` 折转后 `new_dir`、`SPRING` 逐格弹射、`PORTAL` 出口迈步（传至配对端忽略方向，迈出时验方向）。**激光与空中飞石全向自由穿过**，地面滑石遇之停止。 |

### 3. 准入校验与计分调整（修复逆反与误杀）
- **出生点防秒杀准入（Anti-Spawn-Camp Check）**：合法地图必须存在 **至少 `2` 个不同的第 1 回合末无伤坐标 `(hx, hy)`**，且每个该起点均存在一条零机关伤害活过 **Turn 4**（覆盖 Turn 3 红炮与 Turn 4 蓝炮首射）的安全序列。
- **静态可达性降级**：`static_geometry_reachable()` 降级为非阻断诊断警告，彻底不再误杀“无开关炸红门”或“2 格深渊 + 2 箱搭桥”等合法巧思地图；**精确 `author_solution`（`<= 200` 步，最后一步恰好通关）为唯一硬可达性证书**。
- **双榜计分（恢复 `max(CLEARED) == 320.0 == min(TIMEOUT)` 零和铁律）**：
  - 勇者公式与上半场 100% 一致；
  - 魔王 **失守通关分**：`Score_Demon(CLEARED) = 1.7 * D_eff + 150.0 * (T - 1) / 239.0`（上限严格锁死 `320.0 == TIMEOUT 底线`，彻底消除 235 步步行模拟器刷分，并使金库前恶意等待的双方总分增量为 `0`）；
  - 废标替补席位分别绑定独立封存备用图 `backup_full_1 / backup_full_2`，全交叉表排序按完整浮点精度。
